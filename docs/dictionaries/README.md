# 词库管理

从鼠须管输入法菜单选择「词库管理…」。窗口列出用户目录根目录、`cn_dicts/` 和 `en_dicts/` 下的 `.dict.yaml` 文件。

- **导入词库**：选择 UTF-8 Rime `.dict.yaml` 文件，按头部 `name` 保存，并加入 `rime_ice.dict.yaml` 的 `import_tables`。只接受包含实际词条的独立词库，不接受带有非空 `import_tables` 的入口文件，以避免循环引用。同名文件不会覆盖；当前版本要求 name 是不含目录的英文字母、数字、下划线或连字符。
- **移除导入词库**：仅支持移除此窗口导入的词库，同时删除它的雾凇引用。若其他词库仍引用它，则阻止移除。已有基础词库和其他本地词库不会被这个按钮删除。
- **立即更新**：从 `iDvel/rime-ice` 查询 main 的提交 SHA，再从同一提交下载已安装的 `cn_dicts/{8105,41448,base,ext,tencent,others}.dict.yaml` 和 `en_dicts/{en,en_ext}.dict.yaml`。所有下载与名称检查成功后才开始替换。
- **每周自动更新**：勾选后持久保存设置；从上次成功更新时间起每 7 天更新一次。首次勾选会立即检查更新。鼠须管运行时每分钟检查一次；退出或休眠期间错过的更新在恢复运行后补做。失败后至少间隔 6 小时再重试。默认关闭，避免未经设置就改动本地词库。

导入、移除和更新完成后会请求重新部署。窗口显示文件更新结果；部署成功或失败仍通过鼠须管原有通知报告。更新不会覆盖词库入口文件、方案、Lua、自定义补丁、个人词库或用户学习数据库。**如果手动修改过上述雾凇分词库，更新会以官方版本替换它们**；个人词条建议放在单独导入的词库中。

每次修改前，涉及的原文件备份到用户目录 `.squirrel-dictionaries/backups/<唯一标识>/`，设置和导入记录也保存在 `.squirrel-dictionaries/`。写入失败会尝试恢复全部原文件；如果磁盘故障也阻止恢复，请从备份恢复后重新部署。备份暂不自动清理，可在确认词库正常后手动清理旧目录。

此功能仅管理雾凇拼音词库源文件，不是用户学习记录编辑器，不安装或升级整个雾凇方案。若当前方案使用自定义词库入口而非 `rime_ice`，需自行调整入口引用。

## 验证

```sh
bash scripts/dictionaries/test.sh
bash scripts/spacing/build-dev.sh
```

测试涵盖导入/移除引用、重名保护、基础词库保护、无效更新、路径保护、磁盘写入失败回滚、个人短语保留、设置持久化、每周周期与失败重试间隔。开发包使用独立 `~/Library/RimeSpacingDev`，不会自动替换已安装的输入法。
